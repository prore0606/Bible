# 성경-말씀숲 시작 키트

이 폴더를 그대로 프로젝트 폴더로 쓰면 됩니다.

- `CLAUDE.md` — AI 코딩 도구가 매 작업마다 읽는 핵심 규칙
- `docs/spec.md` — 개발 명세서 전체
- `design/screens.html` — 화면 기준 (브라우저로 열어 보세요)
- `design/promo.html` — 스토어 스크린샷·홍보용 화면
- `db/sqlite/001_init.sql` — 기기 안 DB 스키마 (MVP)
- `db/supabase/001_init.sql` — 서버 DB 스키마 (다음 업데이트: 로그인·동기화·우리 포도원)

## 시작하는 법
1. 이 폴더를 Claude Code(또는 Cursor)로 엽니다.
2. `docs/spec.md` 10장 "개발 순서"의 T0부터 차례대로 프롬프트를 붙여 넣습니다.
3. 작업 하나가 끝날 때마다 완료 기준을 직접 확인하고 Git에 커밋합니다.
