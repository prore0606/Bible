## 3. 다시 만드는 방법

원본은 git에 넣지 않습니다(어휘·임베딩 등 불필요한 자료까지 크기가 큼). 받아서 스크립트로 변환합니다.

```bash
git clone https://github.com/crizin/bible-db.git <임의 폴더>
cd <임의 폴더> && git checkout 4bcb50b3ead59d20b4a6b847f5c79ab4cdba6a2c
cd <프로젝트> && node scripts/build-bible.mjs --src <임의 폴더>/data --commit 4bcb50b3ead59d20b4a6b847f5c79ab4cdba6a2c
```

스크립트는 변환하면서 다음을 검사하고, 하나라도 어긋나면 멈춥니다.
- 책 코드가 `src/data/books.ts`에 있는지, 장 수가 같은지
- 절 번호가 1부터 빠짐없이 이어지는지, 중복이 없는지
- 빈 절·앞뒤 공백이 없는지
- 교정 대상 문구가 원본에 정확히 한 번 있는지(출처가 바뀌면 멈춤)

**본문 JSON을 손으로 고치지 않습니다.** 고칠 일이 있으면 `scripts/build-bible.mjs`의 `KRV_FIXES`에 이유와 함께 추가하고 다시 생성합니다.

## 4. 결정 사항

### 4.1 개역한글은 holybible 수집본을 기본으로 하고, 뜻이 달라지는 3곳만 교정

개역한글 수집본이 두 가지 있었습니다.

| 비교 | holybible 수집본 | 대한성서공회 사이트 수집본 |
| --- | --- | --- |
| 장 수 | 1,189 (완전) | **1,188 — 시편 92편 전체가 없음** |
| 번호 이상 | 없음 | 빠진 절 번호 87곳, 중복 절 6곳 |
| 절 번호 체계 | **KJV와 같게 다시 매김** | 대한성서공회 공식(인쇄본) 번호 |
| KJV와 절 수가 다른 장 | 5개 | 100개 |
| 안내 문구 | "(N절에 포함되어 있음)" 21곳 | 없음 |

대한성서공회 수집본은 시편 92편이 통째로 없고 번호가 비어 있어 **그대로는 쓸 수 없습니다.** 반면 holybible 수집본은 66권이 온전하고, 한·영을 절 번호로 짝지어 보여주는 이 앱의 방식(spec 5장 09 읽기)에 맞습니다.

두 수집본의 **본문 글자**는 번호와 관계없이 거의 같습니다. holybible 31,101절 중 상대편에서 같은 문장을 찾지 못한 절은 36절입니다. 이 중 13절은 대한성서공회 수집본에 시편 92편이 없어서, 10절은 두 수집본의 절 나누기가 달라서(느헤미야 7:68-69, 시편 13:5-6 등)이고, 나머지 **13곳이 실제 글자 차이**입니다. 이 13곳 중:

- **뜻이 달라지는 3곳은 대한성서공회 표기로 교정**했습니다 (`KRV_FIXES`).

  | 구절 | holybible | 교정 후 | 이유 |
  | --- | --- | --- | --- |
  | 민수기 18:11 | 내게 돌릴 것이 | **네게** 돌릴 것이 | 하나님이 아론에게 하시는 말씀 |
  | 신명기 9:12 | 낸 내 백성이 | 낸 **네** 백성이 | 하나님이 모세에게 "네가 인도하여 낸 네 백성" |
  | 이사야 48:13 | 하늘에 폈나니 | 하늘**을** 폈나니 | 조사 오류 |

- **나머지 10곳은 철자·띄어쓰기·고유명사 표기 차이**라 원본(holybible)을 유지하고, 아래 4.4의 검수 목록에 남깁니다.

### 4.2 절 번호는 KJV 기준 (결정 D-17)

holybible 수집본의 번호는 KJV와 같습니다. 그래서 **약 100개 장에서 한국어 절 번호가 인쇄된 개역한글 성경과 다릅니다.** 예) 인쇄본의 창세기 32:1("라반이 아침에 일찌기 일어나…")은 이 앱에서 31:55이고, 인쇄본 32:2("야곱이 그 길을 진행하더니…")가 이 앱에서는 32:1입니다. 이 때문에 창세기 31장은 55절, 32장은 32절입니다(인쇄본은 54절, 33절).

| 장점 | 단점 |
| --- | --- |
| 한·영 짝이 거의 완벽히 맞음 (어긋나는 장은 5개뿐) | 교회·성경공부에서 말하는 절 번호와 다른 장이 있음 |
| 66권이 빠짐없이 완전함 | 구절 저장·기록 카드에 표시되는 절 번호도 같은 기준 |

**제안**: MVP는 이대로 가고, 앱 정보에 안내 문구를 넣습니다.
> 절 번호는 영어 성경(KJV)과 맞추었습니다. 일부 장은 인쇄된 개역한글과 절 번호가 다를 수 있습니다.

**나중에 개선하려면**: 대한성서공회 수집본의 빠진 부분(시편 92편 등)을 보완해 공식 번호로 바꾸고, 원본 저장소의 `data/versification/eng.json`(원어↔KJV 절 매핑)으로 한·영 짝을 맞추는 별도 작업이 필요합니다. 구절 ID(`GEN.32.1`)가 바뀌므로 **출시 후에는 하기 어렵습니다 — 바꾸려면 출시 전에 결정**해야 합니다.

### 4.3 "(N절에 포함되어 있음)" 21곳은 그대로 두고 화면에서 구별

원본이 "앞 절에 합쳐진 절"을 알리려고 넣은 문구입니다(예: 신명기 6:19). 본문이 아니라서 `isMergedVerseNote()`로 구별해 **흐리게 표시하고 저장·기도 연결 대상에서 뺍니다.**

신명기 6:19, 15:5, 30:10 · 여호수아 2:13 · 역대상 16:13 · 욥기 31:34, 35:11 · 시편 92:2, 92:3, 105:6 · 이사야 7:9, 30:2, 48:2 · 예레미야 21:2, 32:4, 32:5, 33:11 · 에스겔 24:5, 25:3 · 사도행전 15:26 · 로마서 9:2

## 6. 검증

`tests/lib/bible.test.ts`가 매번 확인하는 것:
- 66권 × 2개 언어 파일, 코드·이름·장 수가 `books.ts`와 일치, 전체 1,189장
