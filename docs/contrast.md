# 색 대비(글자 읽기 쉬움) 점검과 제안

작성일 2026-10-18 · T10에서 다크 테마를 정하며 측정 · **결정 필요: D-27 (밝은 테마의 글자색)**

글자와 배경의 명암비(WCAG)를 계산했습니다. 기준은 **일반 글자 4.5 이상**(큰 글자·굵은 18.7px 이상은 3.0 이상)입니다. 성경 앱은 어르신을 포함해 눈이 침침한 분도 많이 쓰므로, 작은 보조 글자의 대비가 낮으면 실제로 읽기 어렵습니다.

## 1. 다크 테마: 정해서 적용했습니다 (D-05)

명세서가 정한 5개(배경·카드·blue·green·butter) 외에는 제가 대비를 계산해 정했습니다. 적용 후 모든 글자 조합이 4.5 이상입니다(아래 예외 제외).

| 용도 | 값 | 대비 |
| --- | --- | --- |
| 본문 글자 ink `#F2F4F6` (카드/배경) | 새로 정함 | 14.4 / 16.2 |
| 보조 글자 gray `#9AA3AE` (카드/배경) | 새로 정함 | 6.2 / 7.0 |
| 줄·알약 line `#2E2E36`, 저장 구절 형광펜 `#4A4220`, 연한 파랑/초록 배경 | 새로 정함 | 글자 4.9 이상 |
| 보라 글자 grape `#A58BF0` (카드) | 밝게 조정 | 5.7 (원래 `#7C5CDB`는 3.3) |
| 파란 버튼 글자 `on-blue` `#0B1A33` | **어두운 글자로 반전** | 5.7 (흰 글자는 3.0) |
| 달력 완료 칸 `#7C5CDB` + 흰 숫자 | 채움색으로 사용 | 4.8 (밝은 보라는 2.8) |

이를 위해 역할이 다른 토큰 두 개를 추가했습니다: **`on-blue`**(파란 배경 위 글자색), **`grape-solid`**(흰 글자가 올라가는 보라 채움). 밝은 테마에서는 값이 기존과 같아 모양이 바뀌지 않습니다.

## 2. 밝은 테마: 명세서 값에 낮은 조합이 있습니다 — 확인 부탁드립니다 (D-27)

밝은 테마는 **디자인 토큰(명세서 3장)이라 제가 임의로 바꾸지 않았습니다.** 측정 결과입니다.

| 조합 (실제 쓰이는 곳) | 현재 대비 | 판정 |
| --- | --- | --- |
| 보조 글자 gray `#8B95A1` / 카드 · 배경 · 알약 (설정 값, "읽은 뒤에", 시각, 안내문) | 3.0 / 2.8 / 2.7 | ❌ 낮음 |
| 초록 글자 green `#36B37E` / 카드 (포도원 "오늘 자란 것", 구절 번호) | 2.7 | ❌ 낮음 |
| 안내 글자 butter-text `#E8971A` / butter (인사 배너, 안내 상자) | 2.2 | ❌ 낮음 |
| 활성 탭·"붙임" brand `#F5A623` / 배경 · 카드 | 1.9 / 2.0 | ❌ 낮음 |
| 초록 배너 흰 글자 / `#4CC38A`→`#36B37E` (홈 말씀 배너, 기도 화면 말씀 카드) | 2.2 ~ 2.7 | ❌ 낮음 |
| 달력 완료 칸 흰 숫자 / `#A58BF0` | 2.8 | ❌ 낮음 |
| 파란 글자·버튼 흰 글자 blue `#3182F6` | 3.7 | ⚠️ 큰 글자 기준(3.0)만 통과 |
| 본문 ink / 카드, 보라 글자 grape `#7C5CDB` / 카드 | 16.6 / 4.8 | ✅ |

### 제안 (글자에 쓰는 색만 더 진하게, 장식·채움 색은 그대로)

색의 **분위기는 유지**하고, 글자로 쓰는 경우만 진한 변형 토큰을 추가하는 방식입니다. 아이콘·채움·배경은 지금 색 그대로 둡니다.

| 새 글자 토큰 | 값 | 대비 | 바꾸는 곳 |
| --- | --- | --- | --- |
| `gray-text` | `#677281` | 카드 4.9 / 배경 4.5 | 보조 글자 전부 (HTML 디자인에도 `#6B7684`·`#4E5968`이 쓰임) |
| `green-text` | `#1B8456` | 카드 4.7 | 구절 번호, "오늘 자란 것" |
| `butter-text` | `#9A5F0A` | butter 4.8 | 안내 상자 글자 |
| `brand-text` | `#A96A00` | 카드 4.4 / 배경 4.1 | 활성 탭 글자 (아이콘은 brand 그대로) |
| 초록 배너 | 그라데이션을 `#2A9A69`→`#1F8A5B`로 | 흰 글자 3.5 ~ 4.3 | 홈 말씀 배너, 기도 화면 말씀 카드 |
| 달력 완료 칸 | `grape-light` 대신 `grape-solid` 사용 | 4.8 | 완료한 날 칸 |

선택지는 세 가지입니다.
1. **A. 제안대로 적용** (글자 토큰만 진하게). 권장합니다.
2. **B. 일부만 적용** (예: 보조 글자 gray와 안내 글자 butter-text만).
3. **C. 지금 디자인 유지** (명세서 그대로, 대비가 낮은 채로 출시).

A나 B를 고르시면 토큰 값을 `globals.css`와 `spec.md` 3장에 반영하고, 화면을 다시 확인한 뒤 올리겠습니다. 다크 테마는 이미 위 기준을 만족하므로 영향이 없습니다.

## 5. 적용 결과 (D-27, A안 확정 · 2026-10-18)

글자로 쓰는 색만 진한 변형 토큰으로 바꿨고, 아이콘·채움·배경은 명세서 색 그대로입니다.

| 토큰 (밝은 테마) | 값 | 용도 |
|---|---|---|
| gray-text | #5f6b7a | 보조 글자 |
| green-text | #146b45 | 초록 글자 |
| brand-text | #9a5f00 | 활성 탭·강조 글자 |
| butter-text | #9a5f0a | 안내 글자 |
| blue-text | #1b64da | 작은 파란 글자 |

다크 테마에서 스플래시·첫 씨앗 화면 글자가 배경과 거의 같은 색이던 문제(대비 1.0)도 고쳤습니다 (`warm-from/to` 토큰).
